# Tanatloc docker

Docker builder for [Tanatloc](https://github.com/2LTech/tanatloc)

You can find the docker on [Docker Hub](https://hub.docker.com/repository/docker/tanatloc/tanatloc/tags)

## Tips

Update docker/package.json :

```
cd docker
npx npm-check-updates -u
```

Manually check `packageManager` version.
